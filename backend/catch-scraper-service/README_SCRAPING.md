# Catch.co.kr 채용공고 스크래핑 가이드

## 📋 목표
Catch.co.kr에서 최근 채용공고 2000건을 실제로 스크래핑하여 AWS RDS MySQL의 jobs 테이블에 저장

## 🚀 실행 방법

### 1. 터미널 열기
- Windows PowerShell 또는 Command Prompt를 **관리자 권한**으로 실행

### 2. 디렉토리 이동
```bash
cd C:\AI\mini\project\backend\catch-scraper-service
```

### 3. 스크립트 실행
```bash
python scrape_2000_jobs_real.py
```

## ⏱️ 예상 소요 시간
- **약 30분 ~ 1시간** (네트워크 속도 및 페이지 로딩 시간에 따라 변동)
- 페이지당 약 20개 공고 × 100페이지 = 2000건

## 🔧 문제 해결

### Chrome 드라이버 오류 발생 시

1. **Chrome 브라우저 업데이트**
   - Chrome 브라우저를 최신 버전으로 업데이트

2. **관리자 권한으로 실행**
   - PowerShell을 관리자 권한으로 실행

3. **방화벽 확인**
   - Chrome 드라이버의 네트워크 접근 허용

### 중간에 중단된 경우

- 스크립트는 URL 기반으로 중복을 체크하므로, 다시 실행하면 이미 저장된 공고는 건너뜁니다.
- 중단된 시점부터 계속 진행할 수 있습니다.

## 📝 스크립트 파일 위치

- **메인 스크립트**: `scrape_2000_jobs_real.py`
- **데이터베이스**: AWS RDS MySQL (자동 연결됨)
- **저장 테이블**: `jobs`
