# 회사 로고 배치 스크래핑 가이드

## 개요

`batch-scrape-company-logos.js`는 jobs 테이블에 있는 모든 회사의 로고를 Catch.co.kr에서 자동으로 스크래핑하는 배치 프로그램입니다.

## 기능

- jobs 테이블에서 고유한 회사 목록을 자동으로 조회
- 이미 로고가 있는 회사는 건너뛰기
- 로고가 없는 회사만 선택적으로 스크래핑
- 채용공고가 많은 회사부터 우선 처리
- 진행 상황 실시간 표시
- 성공/실패 통계 제공

## 사용법

### 1. 모든 회사 로고 스크래핑

```bash
cd backend
node batch-scrape-company-logos.js
```

### 2. 특정 개수만 스크래핑 (테스트용)

```bash
# 최대 10개 회사만 스크래핑
node batch-scrape-company-logos.js 10

# 최대 3개 회사만 스크래핑 (빠른 테스트)
node batch-scrape-company-logos.js 3
```

## 처리 로직

1. **회사 목록 조회**: jobs 테이블에서 `DISTINCT company` 조회
2. **중복 제거**: 이미 로고가 있는 회사 필터링
3. **우선순위 정렬**: 채용공고가 많은 회사부터 처리
4. **순차 스크래핑**: 각 회사마다 2초 간격으로 스크래핑
5. **결과 저장**: catch_companies 테이블에 company_logo_url 저장

## 주의사항

### 1. 실행 시간
- 회사가 많을 경우 실행 시간이 오래 걸릴 수 있습니다
- 각 회사마다 약 10-15초 소요 (로그인 + 검색 + 스크래핑)
- 100개 회사 기준 약 20-30분 소요 예상

### 2. 서버 부하
- 각 회사 스크래핑 후 2초 대기
- Catch.co.kr 서버에 부하를 주지 않도록 설계됨

### 3. 로그인 정보
- `scrape-company-info.js`에 Catch.co.kr 로그인 정보 필요
- 현재 설정: `test0137` / `#test0808`

### 4. 오류 처리
- 개별 회사 스크래핑 실패 시 다음 회사로 계속 진행
- 전체 배치는 중단되지 않음

## 트러블슈팅

### 문제: "회사 정보는 저장되었으나 로고를 찾지 못함"
- 원인: Catch.co.kr에 해당 회사의 로고 이미지가 없음
- 해결: 정상 동작, 로고가 없는 회사는 프론트엔드에서 기본 디자인 표시

### 문제: "스크래핑 실패"
- 원인: 네트워크 오류, 회사명이 Catch.co.kr에 없음, 로그인 실패 등
- 해결:
  1. 인터넷 연결 확인
  2. Catch.co.kr 로그인 정보 확인
  3. 해당 회사명이 Catch.co.kr에 존재하는지 확인

### 문제: MySQL 연결 오류
- 원인: .env 파일의 DB 설정 오류
- 해결: .env 파일의 DB_HOST, DB_USER, DB_PASSWORD 확인

## 수동으로 특정 회사만 스크래핑

특정 회사의 로고만 스크래핑하려면:

```bash
node scrape-company-info.js "회사명"

# 예시
node scrape-company-info.js "카카오"
node scrape-company-info.js "네이버"
```

## 데이터베이스 스키마

배치 프로그램은 다음 테이블을 사용합니다:

### jobs 테이블
- `company`: 회사명 (스크래핑 대상 목록)

### catch_companies 테이블
- `company`: 회사명 (PRIMARY KEY)
- `company_logo_url`: 회사 로고 이미지 URL
- `url`: 회사 상세 페이지 URL
- `industry`, `company_type`, `employee_count` 등: 기타 회사 정보

## 스케줄링 (선택사항)

정기적으로 배치를 실행하려면 cron 또는 Windows Task Scheduler 사용:

### Linux/Mac (cron)
```bash
# 매일 새벽 2시에 실행
0 2 * * * cd /path/to/backend && node batch-scrape-company-logos.js >> scraping.log 2>&1
```

### Windows (Task Scheduler)
1. 작업 스케줄러 열기
2. 기본 작업 만들기
3. 프로그램: `node`
4. 인수: `C:\path\to\backend\batch-scrape-company-logos.js`
5. 시작 위치: `C:\path\to\backend`

## 관련 파일

- `batch-scrape-company-logos.js`: 배치 스크립트 (이 파일)
- `scrape-company-info.js`: 개별 회사 스크래핑 함수
- `migrations/add_company_logo_url.sql`: 데이터베이스 마이그레이션
