# 회사 정보 스크래핑 가이드

## 📋 목표
Jobs 테이블의 모든 고유 회사(434개)에 대해 Catch.co.kr에서 기업정보를 스크래핑하여 catch_companies 테이블에 저장

## 🎯 수집 정보
각 회사당 다음 정보를 수집:
- 회사명 (name)
- 업종 (industry)
- 기업형태 (company_type)
- 위치 (location)
- 직원수 (employee_count)
- 매출액 (revenue)
- 대표자 (ceo)
- 설립일 (establishment_date)
- 회사 URL (company_url)

## 🚀 실행 방법

### 1. 터미널 열기
- Windows PowerShell 또는 Command Prompt를 **관리자 권한**으로 실행

### 2. 디렉토리 이동
```bash
cd C:\AI\mini\project\backend\catch-scraper-service
```

### 3. 스크립트 실행
```bash
python scrape_company_info.py
```

## 🔧 문제 해결

### 특정 회사를 찾을 수 없는 경우
- Catch.co.kr에 해당 회사 정보가 없을 수 있습니다
- 회사명이 정확하지 않을 수 있습니다
- 이 경우 자동으로 건너뛰고 다음 회사를 처리합니다

### Chrome 드라이버 오류 발생 시
1. Chrome 브라우저를 최신 버전으로 업데이트
2. 관리자 권한으로 PowerShell 실행
3. 방화벽에서 Chrome 드라이버 허용

### 중간에 중단된 경우
- 스크립트는 이미 저장된 회사는 업데이트만 하므로 다시 실행해도 됩니다
- 중복 없이 안전하게 재실행 가능합니다

## 📝 스크립트 파일 위치

- **데이터베이스**: AWS RDS MySQL (자동 연결)

1. **네트워크 안정성**: 안정적인 네트워크 환경에서 실행하세요
