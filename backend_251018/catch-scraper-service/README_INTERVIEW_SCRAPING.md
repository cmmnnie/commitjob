# 면접 기출질문 스크래핑 가이드

## 📋 목표
Jobs 테이블의 모든 고유 회사에 대해 Catch.co.kr에서 면접 기출질문을 스크래핑하여 catch_interview_questions 테이블에 저장

## 🎯 수집 정보
각 회사당 최대 20개의 기출질문 수집:
- 회사명 (company_name)
- 질문 내용 (question)
- 면접 시기 (period)
- 직무 (position)
- 경력 (experience)
- 회사 URL (company_url)

## 🔧 주요 기능

### 1. 중복 방지
- 동일 회사 + 동일 질문 조합은 자동으로 중복 체크
- 재실행 시 이미 저장된 질문은 건너뛰기
- 안전하게 여러 번 재실행 가능

### 2. 로그인 유지
- Catch.co.kr 자동 로그인
- 세션 유지로 효율적인 스크래핑
- 로그인 정보는 스크립트 내부에 설정됨

### 3. 스마트 매칭
- 회사명 정규화 (띄어쓰기 무시)
- 정확 매칭 + 부분 매칭 지원
- 다양한 회사명 형식 처리

### 4. 상세 정보 수집
- 질문 내용 (필수)
- 면접 시기 (예: "2024년 상반기")
- 직무 (예: "백엔드 개발자")
- 경력 (예: "신입", "경력 3년")

## 💾 데이터베이스 구조

```sql
catch_interview_questions (
  id INT AUTO_INCREMENT PRIMARY KEY,
  company_id INT,                    -- catch_companies 테이블 참조
  company_name VARCHAR(255) NOT NULL,
  question TEXT NOT NULL,
  period VARCHAR(100),               -- 면접 시기
  position VARCHAR(200),             -- 직무
  experience VARCHAR(100),           -- 경력
  company_url VARCHAR(1024),
  created_at TIMESTAMP,
  INDEX idx_company_name (company_name),
  INDEX idx_company_id (company_id),
  FOREIGN KEY (company_id) REFERENCES catch_companies(id)
)
```

## 📞 문제 해결

### Chrome 드라이버 오류
- Chrome 브라우저 최신 버전으로 업데이트
- 관리자 권한으로 실행

### 로그인 실패
- Catch.co.kr 계정 정보 확인
- 수동으로 웹사이트 로그인 테스트

### 질문을 찾을 수 없음
- 해당 회사에 기출질문이 없는 것이 정상
- 통계에 '기출질문이 없는 회사'로 카운트됨

### DB 연결 실패
- AWS RDS 접속 정보 확인
- 네트워크 연결 상태 확인
