기본
- BASE_URL: http://아이피:3000/api
- 모든 응답은 JSON. 프론트는 results.*를 사용.
- 중복 제거 목록은 results.unique_jobs.

홈페이지
// 수집/저장
await fetch(`${BASE_URL}/db/refresh/homepage`, { method: 'POST' });

// 조회(중복제거 목록 사용)
const res = await fetch(`${BASE_URL}/db/homepage`).then(r=>r.json());
const unique = res.results.unique_jobs; // 표시에 사용

전체 공고
// 수집/저장(전체 또는 ?max_pages=N)
await fetch(`${BASE_URL}/db/refresh/all`, { method: 'POST' });

// 조회(중복제거 목록 사용)
const res = await fetch(`${BASE_URL}/extract-all-jobs`).then(r=>r.json());
const unique = res.results.unique_jobs;

특정 기업 공고
// GET 권장(한글 쿼리)
const q = encodeURIComponent('카카오');
const res = await fetch(`${BASE_URL}/db/company-jobs?company_name=${q}`).then(r=>r.json());
const unique = res.results.unique_jobs;
